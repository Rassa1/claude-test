How to flash it

      
    
        
  1. Install the Arduino IDE and add ESP32 support (Boards Manager → “esp32” by Espressif).
    2. 
        
  2. Library Manager → install FastLED.
    3. 
        
  3. Paste the code into a new sketch (or open the downloaded .ino).
    4. 
        
  4. Tools → Board → your board (XIAO ESP32-S3 = “XIAO_ESP32S3”), pick the port, press Upload.
    5. 
        
  5. Each input pin is ON when pulled to GND. For 12V car wires use an optocoupler per input (see the code comments).
    6. 
      

      
Check your local laws: rear lights generally must be red (amber for indicators) and can't flash, except signals. Rainbow/sparkle effects are for shows only.
